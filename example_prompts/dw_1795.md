User question: List the unique full room names, their corresponding building names, street addresses, cities, states, postal codes, and building heights for rooms associated with subjects that Computer Science students can enroll in.

Mapping:
"full room names" in the user question refers to column ROOM_FULL_NAME in table fclt_rooms
"building names" in the user question refers to column BUILDING_NAME in table buildings
"street addresses" in the user question refers to column BUILDING_STREET_ADDRESS in table buildings, column ADDRESS_PURPOSE in table fclt_building_address
"cities" in the user question refers to column CITY in table fclt_building_address
"states" in the user question refers to column STATE in table fclt_building_address
"postal codes" in the user question refers to column POSTAL_CODE in table fclt_building_address
"building heights" in the user question refers to column BUILDING_HEIGHT in table fclt_building
"Computer Science" in the user question refers to column DEPARTMENT_NAME in table course_catalog_subject_offered

Join keys:
COURSE_CATALOG_SUBJECT_OFFERED joins FCLT_ROOMS on COURSE_CATALOG_SUBJECT_OFFERED.MEET_PLACE = FCLT_ROOMS.FCLT_ROOM_KEY
FCLT_BUILDING_ADDRESS joins FCLT_ROOMS on FCLT_BUILDING_ADDRESS.FCLT_BUILDING_KEY = FCLT_ROOMS.FCLT_BUILDING_KEY
FCLT_BUILDING joins FCLT_ROOMS on FCLT_BUILDING.FCLT_BUILDING_KEY = FCLT_ROOMS.FCLT_BUILDING_KEY
BUILDINGS joins FCLT_ROOMS on BUILDINGS.BUILDING_KEY = FCLT_ROOMS.FCLT_BUILDING_KEY

Domain knowledge:
"street address" is predicated by "TABLE.ADDRESS_PURPOSE = 'STREET'"
"Computer Science" is predicated by "TABLE.DEPARTMENT_NAME = 'Electrical Eng & Computer Sci'"
