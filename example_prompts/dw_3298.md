User question: List the unique full room names, their corresponding building names, street addresses, cities, states, postal codes, and building heights for rooms associated with subjects that Computer Science students can enroll in.

Mapping:
"full room names" in the user question refers to column ROOM_FULL_NAME in table fclt_rooms
"building names" in the user question refers to column BUILDING_NAME in table buildings
"street addresses" in the user question refers to column BUILDING_STREET_ADDRESS in table buildings, column ADDRESS_PURPOSE in table fclt_building_address
"cities" in the user question refers to column CITY in table fclt_building_address
"states" in the user question refers to column STATE in table fclt_building_address
"postal codes" in the user question refers to column POSTAL_CODE in table fclt_building_address
"building heights" in the user question refers to column BUILDING_HEIGHT in table fclt_building
"Computer Science" in the user question refers to column DEPARTMENT_NAME in table course_catalog_subject_offered

Join keys:
COURSE_CATALOG_SUBJECT_OFFERED joins FCLT_ROOMS on COURSE_CATALOG_SUBJECT_OFFERED.MEET_PLACE = FCLT_ROOMS.FCLT_ROOM_KEY
FCLT_BUILDING_ADDRESS joins FCLT_ROOMS on FCLT_BUILDING_ADDRESS.FCLT_BUILDING_KEY = FCLT_ROOMS.FCLT_BUILDING_KEY
FCLT_BUILDING joins FCLT_ROOMS on FCLT_BUILDING.FCLT_BUILDING_KEY = FCLT_ROOMS.FCLT_BUILDING_KEY
BUILDINGS joins FCLT_ROOMS on BUILDINGS.BUILDING_KEY = FCLT_ROOMS.FCLT_BUILDING_KEY

Domain knowledge:
"street address" is predicated by "TABLE.ADDRESS_PURPOSE = 'STREET'"
"Computer Science" is predicated by "TABLE.DEPARTMENT_NAME = 'Electrical Eng & Computer Sci'"

User question: For each subject offered in the library, show the subject title, number of enrolled students, offering department name, term description, academic year, subject short title, and the maximum total units for each row and the next two rows in order of subject ID, considering only subjects offered in the 'Mathematics' department during regular terms, along with the average, range, and variance of CIP program codes for all courses offered by that department where the department is degree granting and the course level is undergraduate. Present the subject title, number of enrolled students, offering department name, term description, academic year, subject short title, maximum total units, average CIP program code, CIP program code range, and CIP program code variance in that order. Do not return any rounded answers.

Mapping:
"subject offered in the library" in the user question refers to column SUBJECT_TITLE in table library_subject_offered
"subject title" in the user question refers to column SUBJECT_TITLE in table library_subject_offered
"number of enrolled students" in the user question refers to column NUM_ENROLLED_STUDENTS in table library_subject_offered
"offering department name" in the user question refers to column OFFER_DEPT_NAME in table library_subject_offered
"term description" in the user question refers to column TERM_DESCRIPTION in table academic_terms
"academic year" in the user question refers to column ACADEMIC_YEAR in table academic_terms
"subject short title" in the user question refers to column SUBJECT_SHORT_TITLE in table course_catalog_subject_offered
"maximum total units" in the user question refers to column TOTAL_UNITS in table course_catalog_subject_offered
"Mathematics department" in the user question refers to column OFFER_DEPT_NAME in table library_subject_offered
"regular terms" in the user question refers to column IS_REGULAR_TERM in table academic_terms
"average CIP program code" in the user question refers to column CIP_PROGRAM_CODE in table sis_course_description
"CIP program code range" in the user question refers to column CIP_PROGRAM_CODE in table sis_course_description
"CIP program code variance" in the user question refers to column CIP_PROGRAM_CODE in table sis_course_description
"degree granting" in the user question refers to column IS_DEGREE_GRANTING in table sis_department
"undergraduate course level" in the user question refers to column COURSE_LEVEL in table sis_course_description

Join keys:
ACADEMIC_TERMS joins LIBRARY_SUBJECT_OFFERED on ACADEMIC_TERMS.TERM_CODE = LIBRARY_SUBJECT_OFFERED.TERM_CODE
ACADEMIC_TERMS joins COURSE_CATALOG_SUBJECT_OFFERED on ACADEMIC_TERMS.TERM_CODE = COURSE_CATALOG_SUBJECT_OFFERED.TERM_CODE
SIS_COURSE_DESCRIPTION joins SIS_DEPARTMENT on SIS_COURSE_DESCRIPTION.DEPARTMENT = SIS_DEPARTMENT.DEPARTMENT_CODE

Query decomposition:
Subquery 1: For each subject offered in the library, show the subject title, number of enrolled students, offering department name, term description, academic year, subject short title, and the maximum total units for each row and the next two rows in order of subject ID, considering only subjects offered in the 'Mathematics' department during regular terms.
Subquery 2: For each department, give the department name and calculate the average, range, and variance of CIP program codes for all courses offered by that department where the department is degree granting and the course level is undergraduate.
